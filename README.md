# New Dean Education Centre Website

A low-cost, responsive one-page website based on the supplied New Dean Education Centre flyer.

## Included

- New Dean logo cropped from the supplied flyer
- IELTS, Duolingo, PTE and Spoken English course sections
- Admissions CTA
- Call and WhatsApp buttons
- Why New Dean / key features
- About section
- Address and phone details from the supplied flyer
- Google Maps embed for New Ranip, Ahmedabad
- Mobile navigation
- Responsive layout
- Admission flyer used as the main visual reference

## Important customization

The phone numbers, address and course content are based on the supplied flyer. Verify them before publishing.

To change content, edit `index.html`.

To change colors/design, edit `style.css`.

The main brand colors are:
- Navy: #103B70
- Blue: #154D88
- Orange: #E39520
- Red accent: #E53945
- Green accent: #65B83F

## GitHub Pages

1. Create a new GitHub repository.
2. Upload all files and the `images` folder.
3. Open Settings → Pages.
4. Select Deploy from a branch.
5. Select `main` and `/root`.
6. Save.

No backend or paid hosting is required.

## Custom domain

You can later connect a `.in` or `.com` domain to GitHub Pages.
